Error Response Format

HTTP Statusความหมายตัวอย่าง
400ข้อมูลไม่ครบหรือไม่ถูกต้อง{ "status": "error", "message": "โปรดระบุ..." }
401Token หมดอายุหรือไม่ถูกต้อง{ "error": "Unauthorized" }
404ไม่พบข้อมูล{ "status": "error", "message": "ไม่พบข้อมูล" }
500เกิดข้อผิดพลาดภายใน Server{ "status": "error", "message": "..." }
 
{
